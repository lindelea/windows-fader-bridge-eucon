# Windows Fader Bridge for EUCON

Control the Windows audio mixer from an Avid EUCON surface or Avid Control.

**[Download v1.0.0](https://github.com/lindelea/windows-fader-bridge-eucon/releases/latest)**

No build tools are required. Download the installer and start mixing.

[简体中文使用手册](docs/USER_GUIDE.zh-CN.md) ・ [English User Guide](docs/USER_GUIDE.en.md) ・ [日本語ユーザーガイド](docs/USER_GUIDE.ja.md)

![Application overview](docs/images/overview.png)

Use physical faders, encoders and keys for Windows output devices, input devices and individual applications. Volume, pan, mute, solo, channel selection, meters, banking and media information are synchronized in real time.


## Windows audio control for Avid S3 and Avid Control

- Mix individual Windows applications from a EUCON control surface.
- Control the Windows master output and input devices.
- Switch EUCON focus between a DAW, Windows audio, and UAD Console with dedicated commands.
- Use Avid Control even when no physical EUCON surface is attached.

Requirements: Windows 11 x64 and Avid EuControl / EUCON Workstation 2026.4. A compatible EUCON surface or Avid Control is required for control.
